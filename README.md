# CIFAR-10 Image Classification with CNN

An image classification project using a **Convolutional Neural Network (CNN)** built with **PyTorch** to classify images from the CIFAR-10 dataset.

## Dataset Preview

![CIFAR-10 dataset sample images](<img width="575" height="243" alt="image" src="https://github.com/user-attachments/assets/7fc91b17-8e95-4381-88e5-82ea21b07dd7" />

The CIFAR-10 dataset contains 60,000 color images of size 32×32 pixels across 10 classes.

**Classes:** Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, and Truck.

- **Dataset:** [CIFAR-10 — Official Website](https://www.cs.toronto.edu/~kriz/cifar.html)
- **Model:** Convolutional Neural Network (CNN)
- **Framework:** PyTorch
- **Task:** Multi-class image classification

## Objective

Build and train a CNN to learn visual features from small color images and classify them into one of the 10 CIFAR-10 categories.

## Technologies

- Python
- PyTorch
- Torchvision
- Matplotlib

## Dataset Reference
